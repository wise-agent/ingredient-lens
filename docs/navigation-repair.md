# 導覽與成分連結修正

## 2026-10-16 問題回報

使用者回報百科回不到首頁、首頁百科入口不明顯、商品內容物無法連到百科。

## 部署成品檢查

修正前的正式首頁、百科和帶 entry 參數的路由均為 HTTP 200。正式 CSS 與三個主要 JavaScript chunk 逐位元組等於已部署建置，RSC navigation 回應為正確的 text/x-component，沒有登入 HTML 或遺失 chunk 的證據。因此沒有把問題歸咎於舊版伺服器快取。

確認的介面缺陷：
- 手機 CSS 隱藏目前頁面的主導覽，且百科頁會隱藏第一個首頁導覽項目。
- 商品卡片的成分為不可點擊的 span；已匹配的詳情成分也只有展開說明按鈕，真正詞條連結藏在說明內容底端。未匹配成分沒有搜尋入口。
- 百科只監聽 popstate，輸入狀態可蓋過新的網址參數；這是 SPA 同頁導覽的風險，但未將它宣稱為所有使用者失敗的已重現原因。

## 修正原則

首頁與百科使用持續可見的原生 HTML 連結，不依賴 SPA 路由攔截。每一項已辨識成分均可點選：單一精確匹配指向詞條 ID，功能標示指向分類，其餘明示搜尋，不假造身份。說明按鈕與實際連結分開，滑鼠、鍵盤與觸控均有常駐入口。

原料 API 附帶小型參照索引；產品卡片不必先下載整份百科才可產生正確連結。精確查找僅使用官方名稱、英文名稱與核實別名，不使用泛稱 displayNames。原商品資料、包含／排除語義與私人存取政策不變。

## 驗證界線

驗證涵蓋實際元件的 HTML 連結、所有官方名稱與別名索引等價性、建置後路由與 API、正式部署資產和 URL 回應。瀏覽器實際點擊、hover、觸控與視覺驗證仍須與這些測試分開報告；環境限制不代表已通過。
