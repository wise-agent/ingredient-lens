# 成分透鏡 第一版設計

使用者於 2026-10-16 核可原料／分類動態搜尋篩選的前端，並要求重新核實資料完整度。

## 目標
以臺灣食品追溯追蹤公開資料提供手機與桌面可用的商品快速篩選。使用者輸入部分原料名稱，可從分組建議選包含或排除；另有商品、公司、規格及商品分類搜尋。

## 互動
- 原料與原料分類建議分組顯示；優先精確、字首、別名及部分字串。建議最多12項，顯示目前結果中符合該項的數量。
- 條件以文字加色彩的可移除標籤顯示，同一項的新選擇取代舊選擇。
- 包含條件全部成立；任一排除條件命中便移除。空結果不自動放寬。
- 桌面側欄，手機底部篩選面板；數量保持可見。
- 商品詳情保留原始標示、別名／分類依據、來源、日期與照片；同廠警語獨立呈現。
- 分類檢視為唯讀，不建立管理後台。

## 資料與安全邊界
採 Sites Vinext + server API + 原生 D1 持久資料庫。商品、原料、分類及兩張關聯表分離，另存別名及匯入批次紀錄。分類是研究用的暫定詞典，不將天然成分一律當成添加物。圖片失效有替代畫面。

首次使用部分真實資料，統計由稽核後資料檔帶入。成分文字、僅有成分圖片、沒有成分證據分開統計；未 OCR 的圖片不進文字原料篩選。缺漏或解析待確認者不能因為未找到某原料而通過排除條件。分類排除依目前分類規則運作，不會把未分類的普通原料視為添加物；明示分類仍不完整，未命中不等於不含。搜尋結果不是過敏或食安保證。

## 驗收
真實 D1 表及數量可查；包含AND／排除OR／分類階層／切換衝突／缺漏不通過排除／警語分離可測；手機與桌面無溢出；錯誤、空結果、載入、失效圖片都有明確狀態；私人發布且不變更分享範圍。
