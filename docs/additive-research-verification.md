# 添加物研究驗證紀錄

查核日：2026-10-21。研究筆數不是安全認證；狀態以正式 JSON 的 metadata.research 與全量 status.json 為準。

## 整合檢查

- 正式資料僅採 approved-batches.json 核准批次。所有批次 ID 必須存在於原始 717 詞條，且不得重複。
- 主 JSON、API、百科與商品詳情使用同一份資料。狀態統計與全量帳本以測試逐項比對。
- 每條保留六項說明、查核日、直接來源網址及其支持範圍。網址限 HTTPS、不得含帳密；文字透過 React 正常文字輸出。
- 與研究前版本比較，原有詞條的名稱、別名、用途、法規狀態、來源及其他原始欄位保持不變。

## 獨立內容覆核與修正

- 防腐、抗氧化、著色、甜味與膠體資料的高影響評估，另行核對主要官方來源及適用族群。
- 葉酸衍生物不直接套用葉酸對 B12 缺乏的機制；泛醇不直接視同高劑量泛酸的人體資料。
- 礦物來源的專屬報告限相應化合物使用；鈣與鐵的專頁錯配已排除。元素鐵不再稱為鹽類，乳蛋白來源補上過敏依據。
- 胺基酸法規名單不能支持未列的 DL 型或不同鹽形式；硼酸誤食資料僅作特定硼配合物的背景，不冒充其獨立毒理。
- 咖啡因每日分散攝取參考與單次參考分開，並保留孕哺與個別敏感性限制；沒有直接支持的腸胃作用敘述已移除。
- 香料 WHO 資料庫的兩個 CAS 欄位錯誤，經 FAO、FDA 或 NIST 交叉確認後僅在研究說明中更正並揭露差異。
- 香料類別全部保留身分待確認，類內範例不代表全類同樣安全或有害。

## 驗證界線

已執行單元／元件與資料結構測試、型別檢查、正式建置。另以本地 HTTP 檢查 API JSON 精確相等及首頁、百科、詞條深連結成功回應。這些檢查不等於所有瀏覽器的視覺驗收。

正式網站仍有 ChatGPT 私人登入閘門。雲端瀏覽器未登入，尚未驗證正式站登入後畫面或手機視覺與互動；未為驗證改變公開範圍。

## 首輪深度修正

二次稽核發現部分有限證據標籤其實反映本次專屬搜尋尚未完成，而非已確認科學界缺資料。已另加 research-pending 狀態與獨立核准清單；一般背景不得自動升級完成。08-271 原誤寫的中英文 HAP/HVP 矛盾已刪除，原資料兩者均為 HVP，真正待確認的是配體規格。所有後續深查須經 QA 後才解除待查標籤。
