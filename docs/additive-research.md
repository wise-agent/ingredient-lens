# 添加物教育研究

## 範圍與原則

延續官方附表匯入的 717 個百科詞條與既有 ID，包含一般物質、營養添加劑、加工助劑及類群，並非 717 種獨立分子。保留原名稱、別名、法規日期、原料標示、商品關聯與未知分類。研究不改寫台灣准用判定，不產生安全分數。

每筆 `research` 說明身分、加工用途與添加理由、人體影響、高攝取或長期暴露的風險條件、需留意族群、證據限制，並記錄查核日及每個來源支持的範圍。國外風險評估不等於台灣法規。動物研究與人體證據分開；ADI 不是中毒線。缺乏特定危害證據不代表安全，也不應補寫未證實疾病。

## 狀態

2026-10-21 二次稽核：首輪有說明與來源不等於專屬查證完成。一般營養背景、用途索引或尚待核讀的特定形態評估，改列 research-pending，不能包裝成已證實科學界缺資料。

- `research-pending`：尚待專屬查證，現有內容是初步資料，不表示已確認證據不足。

- `reviewed`：已整理可對應該條目的逐項資料；不表示完全安全或資料永遠完整。
- `evidence-limited`：可確認部分資料，但形態、暴露或人體證據有限，限制在條目明示。
- `identity-pending`：類群或具體物質／規格仍待確認，不能由一般名稱產生精確健康結論。
- 未有 `research`：介面明示尚待逐項研究，不隱藏成安全結論。

`research/additive-batches/status.json` 記錄全體狀態；`data/additives.json` metadata.research 記錄精確統計。數量覆蓋與證據充分性必須分開報告。

## 資料流程

研究輸入依第一用途分類分批，合併前逐筆核對 ID 與來源。
`python scripts/merge-additive-research.py` 僅合併 `approved-batches.json` 所列且完成整合 QA、複存於 `approved-content/` 的批次。工作中的 review 檔不會直接進入正式資料，並以 pending-specific-review.json 將尚未通過深查 QA 的項目標為 research-pending；拒絕重複或不存在的 ID，不改原始名稱/來源/用途/法規欄位。

API `/api/additives`、百科與商品說明共用 `data/additives.json`。百科與商品詳情都透過同一 AdditiveEntryDetails 元件呈現研究，不建立另份正式資料庫。

## 保留的界線

成分標示無法提供實際使用量或個人暴露量。沒有辨識到所選成分不等於完全無添加；待確認原料不能視為已證實不含。一般食材不等於無添加，添加物不等於有害，無添加不等於更健康。
