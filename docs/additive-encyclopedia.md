# 添加物百科

既有成分透鏡的新增頁面 `/additives`，以及商品詳情中的成分用途說明。沿用同一 Site、私人存取政策和商品 D1 資料；不重新匯入或改動商品篩選語義。

## 內容與連結

- `data/additives.json` 是附來源、日期及範圍的版本化官方資料整理。`/api/additives` 讀取此唯讀參考資料，頁面按需載入。
- 詞條的中文、英文與有證據別名共用一個識別碼；百科連結與商品說明使用同一詞條。
- 搜尋支援部分名稱，但商品自動關聯僅接受規範化後的完整名稱／已核實別名。模糊或未知名稱不自動判定為特定添加物。
- 大部分用途為附表分類的白話說明；少數依官方原表品項用途整理者另行標示，保留原始證據。所有用途均明示不代表此成分在該商品中的實際用途。
- 香料等類群與單一物質分開標示。來源修正版本含尚未施行內容時，顯示逐項生效提醒及來源說明；不把附表收錄認定為所有食品皆可使用。
- 未收錄名稱顯示未知回退；不附健康好壞評分或安全性結論。

## 互動

百科提供名稱／英文／別名搜尋、用途分類、分頁及來源。商品成分可滑入或鍵盤焦點預覽，點擊固定，重複點擊、關閉按鈕、Escape 或點擊外側關閉。手機使用點擊與明確關閉按鈕。原始成分與過敏／交叉接觸警語保留。

## 驗證

使用名稱對應、分頁與互動狀態單元測試、說明元件伺服器輸出測試、官方資料完整性檢查、TypeScript、官方 Sites 建置及 API 回歸檢查。瀏覽器視覺或真實點擊驗證若受環境限制，須在交付時明確區分為未完成。
