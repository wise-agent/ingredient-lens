# 成分透鏡 Ingredient Lens

面向台灣食品標示的成分查詢、包含／排除篩選與添加物百科。目標是幫助讀者看懂成分的用途，而不是把所有添加物判定為有害，或把「未列出添加物」當成健康保證。

## 功能

- 搜尋產品並依原料及分類設定包含／排除條件。
- 查看產品原始成分、警語、來源及圖片連結。
- 從產品成分連至百科，閱讀加工用途、健康影響的證據與限制。
- 保留未分類、待人工檢查與來源不完整的狀態，避免用缺少資料推論不存在某成分。

## 技術架構

React、TypeScript、vinext／Vite、Tailwind CSS；API 使用 Cloudflare Workers 與 D1。資料庫 binding 名稱為 `DB`。此版本源自 Sites 部署環境，並非已完成通用部署移植的模板。

主要目錄：

- `app/`：畫面與 API routes。
- `lib/`：查詢、分類、百科索引及批次匯入邏輯。
- `data/additives.json`：添加物百科與研究狀態。
- `seed/`：產品資料批次與完整性 manifest。
- `db/`、`drizzle/`（若有）：schema 與資料庫相關檔案。
- `scripts/`：資料準備、匯入、研究合併與開發工具。
- `tests/`：資料、邏輯與介面相關檢查。
- `research/`：研究材料；不代表所有內容都已完成逐項驗證。

## 開發環境

需要 Node.js 22.13.0 或以上；資料處理腳本另需 Python 3。先閱讀 `package.json` 與既有執行腳本，使用鎖定檔對應的套件管理工具。

```sh
npm ci
npm run dev
```

上述是專案的安裝／開發入口，**不是已驗證的全新電腦一鍵啟動保證**。完整產品查詢還需要 D1 schema、`DB` binding 與 seed 匯入。部分執行路徑依賴 Sites 的 execution profile；離開原環境後應先設定自己的 Cloudflare／本機環境，不可沿用原部署身分或私人憑證。

其他既有指令：

```sh
npm run build
npx tsc --noEmit
node --test tests/*.test.mjs
```

瀏覽器與 API smoke tests 需要對應的測試服務、資料與設定。此公開快照不宣稱在所有平台通過上述測試。

## 資料庫與初始化

1. 在自己的環境準備 D1 資料庫與 schema，binding 設為 `DB`。
2. 檢查 `seed/manifest.json` 的版本、表格批次及雜湊。
3. 閱讀 `scripts/import-seed.py` 與 `app/api/initialize/route.ts`，在受控環境完成批次匯入。
4. 核對匯入狀態、筆數與查詢結果。

## 產品資料來源與範圍

主要來源為台灣政府開放資料「非追不可產品追溯追蹤資訊」：

- [政府資料集](https://data.gov.tw/dataset/33575)
- [TFDA 下載入口](https://data.fda.gov.tw/data/opendata/export/188/json)
- [政府資料開放授權條款第 1 版](https://data.gov.tw/license)

本快照的 manifest 記錄於 2026-10-16 擷取 50,769 筆產品，其中 2,030 筆有成分文字，1,657 筆可由目前規則解析。擷取日期不是每筆產品的實際更新日期；資料集也不等同台灣全部市售食品。最新數字及定義請以 `seed/manifest.json` 為準。

圖片連結未全面驗證。沒有成分文字不代表沒有添加物；可解析也不代表標示完整或已人工核實。依分類排除的結果，仍需回看產品原始標示，尤其是過敏原與特殊飲食需求。

## 添加物研究狀態

2026-10-21 版本共 717 個百科條目（含群組，不等於 717 種單一化學物質）：345 個 reviewed、198 個 evidence-limited、67 個 identity-pending、107 個 research-pending。這是工作流程分類，不是品質、安全或醫療認證；部分條目仍需原文資料或身分核對。

用途與健康資訊應附具體來源，區分一般食用條件、高暴露研究、敏感族群與證據不足。不能僅由成分名稱推算攝取量；ADI 不是超過一次就會中毒的門檻。百科不取代醫療建議，也不構成產品安全背書。
